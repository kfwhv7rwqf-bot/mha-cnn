# 成果说明与材料审计

## 项目概述

**基于多头注意力机制与卷积神经网络（MHA-CNN）的环境绩效预测研究**<br>
负责人 | 2022.04 - 2024.07

项目面向碳排放绩效指标多目标预测中变量非线性耦合、特征权重难量化的问题，构建 MHA-CNN 融合模型。模型以 8 个区域层面变量预测 4 项碳排放绩效指标，并借助注意力机制开展变量贡献分析与产业结构优化解释。

## 数据口径

- MHA-CNN 的 `R = 0.92, MAE = 0.04, MSE = 0.003` 是论文中 **TFCE 测试集** 的结果。
- 论文原文将 `R` 记为 correlation coefficient；公开仓库不将其改写为 `R²`。
- ESI 与引用数据会随数据库更新而变化，仓库中的证据截图仅代表其标示的 2025 时间点。
